# Illustration prompts — Movement

Prompts for generating the app's illustrated plates in ChatGPT (or any image tool).
Your four generated images are already in and look great — these are the remaining **twelve**,
and every one has a slot waiting in the app.

> **Status: all 16 plates are complete.** Every prompt below has been generated and wired into the
> app with calibrated hotspots — 118 clickable labels in total. Keep this file as the style
> reference for any *new* plate you want to add.

## How to use

1. Copy a prompt below (each is self-contained — paste as-is).
2. Generate. If the first result is off, ask for "same style, but seen from directly above" or
   "cleaner, less clutter".
3. Save the image to `public/illustrations/` with the **exact filename** listed.
4. Tell me it's in and I'll calibrate the clickable hotspots to your composition.

## Rules that make these work

- **No text in the image.** Image models garble small labels ("Crown a Stem"). The app overlays
  accurate, clickable labels itself — that's the whole design.
- **Landscape, ~4:3**, at least 1600px wide.
- Keep the **same style block** on every prompt (it's the trailing paragraph) so the set matches.
- Straight-on views work best; the hotspot dots sit on a flat plane.

## If a result still misses

Reply to the image in the same chat rather than starting over — it keeps the style:

- **"Same style, but seen from directly above."** — fixes tilted/3-quarter views (the hotspot dots
  assume a flat plane).
- **"Same image, but remove all text and lettering."** — the single most common problem.
- **"Simplify: fewer parts, more space between them."** — when it's too busy to label.
- **"Keep the cream paper background and matte finish."** — if it drifts glossy or dark.

## Fix phrases to paste onto any prompt

- Overlapping parts → `clearly separated with visible gaps between each part`
- Too fantastical → `realistic, plain and industrial — not steampunk or fantasy`
- Unwanted writing → `no numerals, no writing, completely blank surfaces`
- Wrong angle → `viewed straight from above, flat-on, no perspective tilt`
- Too dark/glossy → `matte finish, plain cream paper background, soft even lighting`
